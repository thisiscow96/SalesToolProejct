## 실제 캡처(PNG)

- `images/00-*`~`06-*.png` — 2026-11-20 이전 화면 캡처.
- `images/17-*`~`22-*.png` — 2026-11-25 경락 시세·매입서 대조 화면. 테스트 서버(목업 경락·가명 데이터, 1366px)에서 찍은 실제 화면입니다(`18-pdoc-manual.png`만 화면 개발 단계의 목업 응답 캡처). 운영 데이터·실명은 들어 있지 않습니다.
  - 결함 수정 뒤(`ai/T-203-fix` `f73d45a`, 2026-11-25 오후) 다시 찍은 6장: `17-auction-empty-holiday`·`18-pdoc-result`·`18-pdoc-candidate`(근거 없이 등록 + 판매툴 품목)·`18-pdoc-candidate-out`(허용 밖 후보)·`18-pdoc-review`(검토 대기 목록)·`19-purchase-badge`(매입정보의 「매입서」 배지). 같은 테스트 서버·가명 데이터입니다.

## 삽화(SVG)

**`images/*.svg`** — 매뉴얼용 **자리표시** 이미지(텍스트 안내). Git에 포함되어 있으며 GitHub에서 Markdown 미리보기 시 표시됩니다.

## 실제 스크린샷(PNG)으로 교체할 때

1. 브라우저에서 캡처 후 `images/` 에 저장.
2. `운영자-사용자-매뉴얼.md` 에서 해당 줄의 `.svg` 를 `.png` 로 바꾸거나, 같은 베이스 이름의 PNG를 쓰도록 링크 수정.

(선택) Windows에서 래스터 PNG를 만들려면 `scripts/Generate-PlaceholderImages.ps1` 는 **UTF-8 BOM** 저장 후 실행해야 한글이 깨지지 않을 수 있습니다. **SVG가 기본**이므로 스크립트는 필수 아님.
